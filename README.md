# 🐍 Python Mini Projects

This repository contains a collection of beginner-friendly and intermediate Python mini projects. These projects are designed to help you understand core concepts like algorithms, data structures, control flow, user input handling, and more — all through hands-on practice.

## 📁 Projects Overview

| Project Name                | Description                                                                 |
|----------------------------|-----------------------------------------------------------------------------|
| `binary_search.py`         | Implements binary search to find an element in a sorted list                |
| `student_grading_system.py`| A simple system to calculate and assign grades based on student scores      |
| `tic_tac_toe.py`           | Two-player TicTacToe game playable in the terminal                          |
| `todo_list.py`             | Terminal-based to-do list manager with file storage support                 |
| `calculator.py`            | Command-line calculator that supports basic arithmetic operations           |
| `merge_sort.py`            | Python implementation of the Merge Sort algorithm                           |
| `password_checker.py`      | Checks the strength of a password using basic rules and scoring             |
| `queue.py`                 | Basic queue implementation using list or collections.deque                 |

## ✅ Requirements

- Python 3.x  
- No external dependencies required (all standard libraries)  
- Optional: `colorama` or `prettytable` (if you enhance the UI)
